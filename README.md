# PBL Object Detection

## Project
Object Detection of 3D-Printed Box Using Transfer Learning with YOLO.

## Objective
This project aims to detect a 3D-printed box using a YOLO model through transfer learning.

## Project Structure
- dataset/ : Dataset images and labels
- scripts/ : Python scripts
- results/ : Training and detection results
- requirements.txt : Python dependencies
- .gitignore : Files excluded from Git

## Workflow
1. Collect dataset
2. Annotate images
3. Prepare dataset
4. Train YOLO using transfer learning
5. Evaluate the model
6. Test object detection
7. Document the results
